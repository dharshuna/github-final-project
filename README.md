# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a Bash script that calculates simple interest based on the principal amount, annual rate of interest, and time period entered by the user.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- **Principal:** The initial amount of money.
- **Rate:** The annual rate of interest in percentage.
- **Time:** The investment period in years.

## How to Run
1. Open a terminal in the project directory.
2. Run the script using:

   `bash simple-interest.sh`

3. Enter the principal amount, rate of interest, and time period when prompted.
4. The script displays the calculated simple interest.

## Example
- Principal: 1000
- Rate: 5%
- Time: 2 years
- Simple Interest: 100.00
